# Common Context for rental Agent - premium Tier

This directory contains context files that are shared across all steps in the premium tier for the rental agent.

## Usage

Place `.txt` or `.md` files in this directory. These files will be automatically loaded and included in all AI prompts for premium tier analysis steps.

## File Format

- Supported extensions: `.txt`, `.md`
- Files are concatenated in alphabetical order
- Each file's content is prefixed with its filename as a header

## Examples

- Legal texts specific to premium tier analysis
- Reference documents for premium tier
- Common definitions for premium tier steps
