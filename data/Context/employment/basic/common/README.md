# Common Context for employment Agent - basic Tier

This directory contains context files that are shared across all steps in the basic tier for the employment agent.

## Usage

Place `.txt` or `.md` files in this directory. These files will be automatically loaded and included in all AI prompts for basic tier analysis steps.

## File Format

- Supported extensions: `.txt`, `.md`
- Files are concatenated in alphabetical order
- Each file's content is prefixed with its filename as a header

## Examples

- Legal texts specific to basic tier analysis
- Reference documents for basic tier
- Common definitions for basic tier steps
